# CargoDesk

საბაჟო დეკლარაციების PDF-ებიდან მონაცემების ამოსაღები და Neon Postgres-ში შესანახი ვებაპლიკაცია.

## გაშვება

1. დააკოპირეთ `.env.example` ფაილი `.env` სახელით.
2. Neon-ში შექმენით Postgres პროექტი და `.env`-ში `DATABASE_URL` მნიშვნელობად ჩასვით კავშირის სტრიქონი (`sslmode=require`-ით).
3. ტერმინალში გაუშვით:

   ```powershell
   npm.cmd install
   npm.cmd run dev
   ```

სერვერი Neon-თან HTTPS-ით უკავშირდება. `--use-system-ca` ოფცია Windows-ის სანდო სერტიფიკატების საცავს იყენებს; `npm run dev` და `npm start` მას ავტომატურად რთავს.

4. გახსენით Vite-ის მიერ ნაჩვენები მისამართი (ჩვეულებრივ `http://localhost:5173`).

სერვერი გაშვებისას Neon ბაზაში ავტომატურად ქმნის `declarations` ცხრილს. ატვირთული PDF დროებით მუშავდება მეხსიერებაში; ბაზაში ინახება ამოღებული ველები და საწყისი ფაილის სახელი, თავად PDF კი ბაზაში არ ინახება. ფაილის მაქსიმალური ზომაა 20 მბ.

## მხარდაჭერილი ველები

გრაფა A-ს C ნომერი და თარიღი, გრაფა 2-ის EX ექსპორტიორი და IM იმპორტიორი, გრაფა 4-ის დეკლარანტი, გრაფა 15-ის გამომგზავნი ქვეყანა, გრაფა 31-ის საქონლის აღწერა, გრაფა 33-ის საქონლის კოდი, გრაფა 35-ის ბრუტო წონა და გრაფა 49-ის საწყობის დასახელება. PDF-ის ველების განლაგებაც მხედველობაში მიიღება. `2902.pdf`-ის ფორმატზე რეგრესიული ტესტი არსებობს.

PDF-დან ტექსტის ამოღების შემდეგ მონაცემები დადასტურებამდე რედაქტირებადია. დასკანერებული PDF-იდან ტექსტი ავტომატურად ვერ ამოიღება; ასეთ შემთხვევაში ველები ხელით უნდა შეივსოს. OCR ამ ვერსიაში არ არის ჩართული.

## ჯარიმის კალკულატორი

გვერდითა მენიუში არსებული კალკულატორი იღებს საქონლის რაოდენობას კილოგრამებში, საბაჟო ღირებულებას ლარში და აქციზის განაკვეთს ლარში ტონაზე. აქციზი გამოითვლება რაოდენობისა და კილოგრამზე გადაყვანილი განაკვეთის ნამრავლით; დღგ არის საბაჟო ღირებულებისა და აქციზის ჯამის 18%, ხოლო ჯარიმის თანხა — აქციზისა და დღგ-ის ჯამი.

## წარმოებაში გაშვება

```powershell
npm.cmd run build
npm.cmd start
```

წარმოების სერვერი `dist` საქაღალდიდანაც ემსახურება ფრონტს. საჭიროების შემთხვევაში `PORT`-ის შეცვლა `.env`-ში შეგიძლიათ.

### Render-ზე განთავსება

1. Render Dashboard-ში შექმენით ახალი **Blueprint** და აირჩიეთ `Sandrinio13/CargoDesk` რეპოზიტორია. `render.yaml` ავტომატურად აყენებს Node.js-ის ვერსიას, build/start ბრძანებებს და health check-ს. Build ბრძანება development dependencies-საც აყენებს, რადგან Vite build-ისთვის არის საჭირო, მიუხედავად `NODE_ENV=production` პარამეტრისა.
2. Render-ის გარემოს ცვლადებში `DATABASE_URL`-ის მნიშვნელობად ჩასვით Neon-ის კავშირის სტრიქონი (`sslmode=require`). საიდუმლო კავშირი GitHub-ზე არ ატვირთოთ.
3. შექმენით Blueprint და დაელოდეთ build-ისა და `/api/health` health check-ის წარმატებით დასრულებას. შემდეგ გახსენით Render-ის მიერ შექმნილი `onrender.com` მისამართი.

უფასო Render სერვისი უმოქმედობისას ითიშება, ამიტომ ხელახლა გახსნისას პირველი მოთხოვნა შეიძლება დაგვიანდეს. Neon-ში შენახული მონაცემები სერვისის გათიშვისასაც რჩება. უფასო Render გეგმას მუდმივი დისკი არ აქვს; ეს აპლიკაცია PDF-ს მხოლოდ დროებით, მეხსიერებაში ამუშავებს.
